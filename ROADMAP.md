# 7stories Product Roadmap

Competitive gap analysis vs **Higgsfield (higgsfield.ai)** and **OpenArt (openart.ai)**.
Last reviewed: 2026-08-13.

## Priority 1 — build next
1. **Character Builder** — save a reference photo as a reusable "character"; recall it across
   sessions so the same face appears in any story/scene. (OpenArt's most-loved feature;
   Higgsfield "Photodump/Soul — different scenes, same star.")
2. **Platform presets** — one-click output presets: TikTok/Reels/Shorts (9:16), YouTube/ads
   (16:9), Instagram (1:1), cinematic (21:9). Maps to existing aspect-ratio + resolution.

## Priority 2
3. **Multi-scene Director** — template-driven multi-scene workflows: Short Film, Product Ad,
   UGC Ad, Music Video, Brand Story. Chains several generations into one sequence.
4. **Daily free credits** — grant a small free credit allowance daily (retention).
5. **Motion & camera control** — expose motion strength / camera move params on video models
   that support them.

## Priority 3
6. **Public community showcase** — publish stories/generations publicly with visible prompt +
   assets (network effect, SEO).
7. **Upscale** — add an AI upscaler for images/videos (needs a provider).
8. **Image/video editing** — inpaint/edit, background change, relight.
9. **MCP / API product** — market `/api/generate` as an API/MCP so agents can create.

## Already shipped (not on board)
- Multi-provider models (text/image/video) · reference photos · edit/regenerate/redesign ·
  credits + pricing + purchase · auth + library + documents · analytics ·
  docs + tutorials · SEO + sitemap · video gallery · prompt enhancer ·
  tone/language/size controls · server-side credit consumption.
